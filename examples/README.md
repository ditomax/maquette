# Example results — maquette

These files are **fictitious examples** (Example GmbH, maquette `OFA` "Offer draft assistant", and maquette `EXF` "Service report assistant" from the focus track). They show what a finished result looks like — they are not templates; the templates live in `../templates/`.

- `10-seed.md` — written by stage 1, sparring, prefilled from shortlist entry EXG-001.
- `60-brief.md` — written by stage 6, brief: demo script, can/cannot list and the handover to build (contract H2/3, started from a shortlist entry — "No register").
- `60-brief-register.md` — a brief started from an idea register (contract register/1, taken over as register v2 during the maquette): Part 3 *Register and coverage* with every R-ID, its final coverage and the maquette's own items `R-M1`, `R-M2`.

Stages 2–5 (plan, design, build, harden) also produce result files (`20-plan.md`, `30-design.md`, `40-build.md`, `50-harden.md`) and the clickable HTML prototype in `vcode/`; they are not shown here.

Every real result file has the same frontmatter and the same headings as its template, in the same order.
